Emberward: a top-down arena survival game in plain Canvas 2D with no libraries and no network requests. You are the Warden of the last ember — dodge and burn ten waves of shadow-kind, dash through danger, mend your wounds in the ember's ring, and hold the light until dawn. WASD to move, mouse to aim, hold click to shoot, Space to dash. Synthesised Web Audio sound, particles, combos, pickups, and a seeded autopilot that stages the screenshots.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
